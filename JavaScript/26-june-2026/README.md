| Topic                     | Yaad rakhne wali baat                                         |
| ------------------------- | ------------------------------------------------------------- |

| `null`                    | Programmer khud empty value assign karta hai.                 |

| `undefined`               | JavaScript automatically deta hai jab value assign nahi hoti. |

| `NaN`                     | Invalid mathematical result; `typeof NaN` = `"number"`.       |

| `isNaN()`                 | Value ko pehle number mein convert karke check karta hai.     |

| `Number.isNaN()`          | Sirf asli `NaN` ko `true` return karta hai.                   |

| `Infinity`                | `1 / 0` ka result `Infinity` hota hai.                        |

| `-Infinity`               | `-1 / 0` ka result `-Infinity` hota hai.                      |

| `Number.MAX_VALUE`        | JavaScript ka sabse bada finite number.                       |

| `Number.MIN_VALUE`        | Sabse chhota positive number.                                 |

| `Number.MAX_SAFE_INTEGER` | Safely represent hone wala sabse bada integer.                |

| `Number.MIN_SAFE_INTEGER` | Safely represent hone wala sabse chhota integer.              |

| `Number.EPSILON`          | Floating-point precision compare karne ke liye use hota hai.  |
